# Sources and selected examples

Tangyixiao Workflow is the versioned workflow toolkit at
[tangyixiao/tangyixiao-workflow](https://github.com/tangyixiao/tangyixiao-workflow).
Its initial implementation is `0.1.0-alpha.1`; a source version is not an npm or
product-release publication claim.

## Earlier standard and examples

The earlier Tangyixiao Open Source Standard (TOSS) provides the project-identity,
community, evidence, and resource-management foundation. Its account-level
community defaults remain in `tangyixiao/.github`; they are not duplicated here.

- [TOSS standard at merged main revision 843e1909](https://github.com/tangyixiao/.github/blob/843e1909f82dad054f9dbfef748392c436d850a5/docs/standard.md)
- [Multilingual project website source at the same revision](https://github.com/tangyixiao/.github/tree/843e1909f82dad054f9dbfef748392c436d850a5/site)
- [README examples at selected revision f65a02e7](https://github.com/tangyixiao/.github/tree/f65a02e71a771249700e2239ae1091bed9d7dc31/examples/readme)
- [Chinese README example](https://github.com/tangyixiao/.github/blob/f65a02e71a771249700e2239ae1091bed9d7dc31/examples/readme/README.md) and [English example](https://github.com/tangyixiao/.github/blob/f65a02e71a771249700e2239ae1091bed9d7dc31/examples/readme/README.en.md)
- [Example adoption and rights guide](https://github.com/tangyixiao/.github/blob/f65a02e71a771249700e2239ae1091bed9d7dc31/examples/readme/ADOPTING.md)

The latter snapshot is the selected source from [.github PR #2](https://github.com/tangyixiao/.github/pull/2);
that reference does not assert the PR's current merge state. Fixed revisions make
the example reproducible; they do not promise that its project versions remain
current. Verify receiving-project identity and facts before adoption.

This repository links the selected examples instead of copying their image
history, third-party platform art, fonts or dependencies. An OJ NEXUS illustration
does not become another project's screenshot or product identity. Follow the
upstream license/NOTICE and asset-specific conditions before copying any material.

## Release-note editing examples

The local [0.6.3](../examples/release-notes/zcode-0.6.3.md) and
[0.5.1](../examples/release-notes/zcode-0.5.1.md) examples are user-facing editorial
rewrites, not new releases or records of current installation. Facts were checked
against the existing releases and their corresponding source revisions on 2026-11-17:

- [ZCode Plan Bridge v0.6.3 release](https://github.com/tangyixiao/dsh-zcode-plan-bridge/releases/tag/v0.6.3), [source 4e6526ed](https://github.com/tangyixiao/dsh-zcode-plan-bridge/tree/4e6526ed5726f6fe61400010c06a25766c7d1e21)
- [ZCode Plan Bridge v0.5.1 release](https://github.com/tangyixiao/dsh-zcode-plan-bridge/releases/tag/v0.5.1), [source 8a7ec736](https://github.com/tangyixiao/dsh-zcode-plan-bridge/tree/8a7ec7364dffd8c8c468ce8cbcae26cc716a9c5a)

The 0.5.1 source and release identify the TGZ installation route; the example does
not infer that the registry currently lacks this version or invent an old npm
publication. Its checksum comes from the original notes because that release did
not supply a separate checksum asset. Independent products sharing the source
repository keep their own history.
