Project features

Call the Skill for writing tasks. Use the local CLI when a project needs ongoing configuration checks or is preparing a release.

Draft a README or pull request

Call $tangyixiao-workflow in the target repository. Ask it to use the contribution guide, PR template and your changes to draft a pull request.

You can use the Skill without running adopt. It can also draft release notes for the people who use the project.

Check configuration and release files

Run adopt to preview changes. Once applied, use check to verify the project configuration and the managed section of AGENTS.

Before a release, use release-check to verify the candidate version, Git tag and SHA-256 hashes of the declared files offline.
